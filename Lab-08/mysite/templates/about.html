О проекте Django Articles

Django Articles — учебное веб-приложение, разработанное с использованием Python и веб-фреймворка Django.

Возможности проекта

  • Просмотр списка опубликованных статей.
  • Открытие подробной информации о статье.
  • Отображение изображений статей.
  • Регистрация новых пользователей.
  • Авторизация и выход из аккаунта.
  • Управление материалами через Django Admin.

Используемые технологии

Python, Django, HTML, CSS и SQLite.
