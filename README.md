# MVC-Web-Development-Labs

Лабораторные работы по дисциплине **«Разработка web-приложений на основе MVC-фреймворка»**.

## Описание

Репозиторий содержит лабораторные работы по изучению веб-разработки с использованием Python и Django, принципов архитектуры MVC и организации веб-приложений.

## Используемые технологии

- Python
- Django
- SQLite
- Visual Studio Code
- Git и GitHub

## Лабораторные работы

### Лабораторная работа №1 — Установка и настройка Django

**Цель:** изучить установку Python, настройку среды разработки, создание виртуального окружения и запуск Django-проекта.

**Выполненные задачи:**

1. Установка и проверка Python.
2. Настройка Visual Studio Code.
3. Создание виртуального окружения.
4. Установка Django.
5. Создание проекта `mysite`.
6. Запуск локального сервера.
7. Проверка работы сайта в браузере.

**Каталог:** `Lab-01/`

## Запуск проекта

Перейти в каталог лабораторной работы:

```powershell
cd Lab-01
```

Создать виртуальное окружение:

```powershell
py -m venv .venv
```

Активировать окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Выполнить миграции:

```powershell
python manage.py migrate
```

Запустить сервер:

```powershell
python manage.py runserver
```

После запуска открыть http://127.0.0.1:8000/.

### Лабораторная работа №2 — Ссылки и представления

**Цель:**  изучить механизм обработки HTTP-запросов, создания представлений и настройки URL-маршрутов в Django.

**Выполненные задачи:**

1. Создан файл views.py.
2. Реализована функция homepage() для главной страницы.
3. Настроен маршрут /.
4. Реализована функция about() для страницы информации о компании.
5. Настроен маршрут /about/.
6. Добавлены параметры company_name и company_phone.
7. Реализована передача параметров через kwargs.
8. Проверена работоспособность страниц в браузере.

**Доступные страницы**

/ — главная страница Home.

/about/ — страница About с информацией о компании.

**Каталог:** `Lab-02/mysite`

## Запуск проекта

Из корневой папки репозитория:

cd Lab-02\mysite
python manage.py migrate
python manage.py runserver

Перед запуском необходимо активировать виртуальное окружение с установленным Django.

## Лабораторная работа №3 — Шаблоны

**Цель работы:** изучить создание и подключение HTML-шаблонов в Django, а также передачу данных из представлений в шаблоны.

### Выполненные задачи

1. Создана папка `templates`.
2. Созданы HTML-шаблоны `homepage.html` и `about.html`.
3. Настроен поиск шаблонов через `settings.py`.
4. Реализовано отображение страниц с помощью функции `render()`.
5. Настроены URL-маршруты главной страницы и страницы About.
6. Реализована передача данных через `context`.
7. Выведены строки, списки, словари и кортежи в HTML-шаблонах.
8. Проверена работоспособность страниц в браузере.

### Структура проекта

- `Lab-03/mysite/manage.py` — управление Django-проектом.
- `Lab-03/mysite/mysite/views.py` — представления.
- `Lab-03/mysite/mysite/urls.py` — маршруты.
- `Lab-03/mysite/mysite/settings.py` — настройки.
- `Lab-03/mysite/templates/homepage.html` — главная страница.
- `Lab-03/mysite/templates/about.html` — страница информации о компании.

### Запуск

После активации виртуального окружения с установленным Django:

```powershell
cd Lab-03\mysite
python manage.py migrate
python manage.py runserver
```

### Результат

Созданы две динамические веб-страницы, отображающие данные, переданные из Python в HTML-шаблоны Django.
