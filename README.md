# MVC Web Development Labs

Репозиторий с лабораторными работами по дисциплине **«Разработка веб-приложений на основе MVC»**.

В ходе выполнения лабораторных работ разрабатывается веб-приложение **Django Articles** — сайт для публикации и просмотра статей с поддержкой изображений, регистрации и авторизации пользователей.

Проект реализован на языке Python с использованием веб-фреймворка Django и архитектурного подхода MTV (Model–Template–View).

## Установка и запуск

### 1. Клонирование репозитория

```powershell
git clone https://github.com/Dantalian6730/MVC-Web-Development-Labs.git
cd MVC-Web-Development-Labs
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install django pillow
```

### 4. Переход в папку последней завершённой лабораторной

```powershell
cd Lab-08\mysite
```

### 5. Применение миграций

```powershell
python manage.py migrate
```

### 6. Создание администратора (при необходимости)

```powershell
python manage.py createsuperuser
```

### 7. Запуск сервера

```powershell
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000/

## Особенности реализации

**Архитектура MTV**

Проект использует архитектуру Django MTV:

- Model — модели данных и взаимодействие с базой данных.
- Template — HTML-шаблоны пользовательского интерфейса.
- View — обработка HTTP-запросов и подготовка данных для шаблонов.

**Безопасность**

Для работы с учётными записями используются встроенные средства Django: `UserCreationForm`, `AuthenticationForm`, `login()`, `logout()` и CSRF-защита.

**Работа с изображениями**

Изображения статей загружаются через `ImageField`. Для обработки файлов используется Pillow, а для хранения загруженных изображений настроены параметры `MEDIA_ROOT` и `MEDIA_URL`.
