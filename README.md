# MVC-Web-Development-Labs

Лабораторные работы по дисциплине **«Разработка web-приложений на основе MVC-фреймворка»**.

## Описание

Репозиторий содержит лабораторные работы по изучению веб-разработки с использованием Python и Django, принципов архитектуры MVC и организации веб-приложений.

## Используемые технологии

- Python
- Django
- SQLite
- Visual Studio Code
- Git и GitHub

## Лабораторные работы

### Лабораторная работа №1 — Установка и настройка Django

**Цель:** изучить установку Python, настройку среды разработки, создание виртуального окружения и запуск Django-проекта.

**Выполненные задачи:**

1. Установка и проверка Python.
2. Настройка Visual Studio Code.
3. Создание виртуального окружения.
4. Установка Django.
5. Создание проекта `mysite`.
6. Запуск локального сервера.
7. Проверка работы сайта в браузере.

**Каталог:** `Lab-01/`

## Запуск проекта

Перейти в каталог лабораторной работы:

```powershell
cd Lab-01
```

Создать виртуальное окружение:

```powershell
py -m venv .venv
```

Активировать окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

Выполнить миграции:

```powershell
python manage.py migrate
```

Запустить сервер:

```powershell
python manage.py runserver
```

После запуска открыть http://127.0.0.1:8000/.

## Лабораторная работа №5 — Модели и миграции, ORM

**Цель работы:** изучить создание моделей Django, работу с миграциями, ORM и административной панелью.

### Выполненные задачи

1. Создана модель `Article` с полями `title`, `slug`, `body` и `date`.
2. Созданы и применены миграции базы данных.
3. Изучена работа с Django ORM через интерактивную оболочку Django Shell.
4. Создана и сохранена первая статья через ORM.
5. Реализован метод `__str__()` для строкового представления объектов.
6. Создан суперпользователь Django.
7. Модель `Article` зарегистрирована в административной панели.
8. Создана вторая статья через Django Admin.
9. Изучена структура базы данных SQLite и таблицы `articles_article`.

### Основные команды

```powershell
cd Lab-05\mysite
python manage.py makemigrations
python manage.py migrate
python manage.py shell
python manage.py createsuperuser
python manage.py runserver
```

### Результат

Создана модель статей и соответствующая таблица в базе данных SQLite. Реализована возможность управления статьями через Django ORM и административную панель.
